RAM STORE WEBSITE
=================

Features
- Mobile-first smart grocery UI inspired by the supplied reference layout.
- Grocery catalog with categories and search.
- NO fruits are included.
- Vegetable category contains ONLY Potato and Onion.
- Cart with quantity controls and localStorage persistence.
- Customer name, phone number and delivery address.
- Download selected grocery list as a .txt file.
- Send complete order to the owner's WhatsApp.
- Manual/offline delivery and offline payment wording.
- Footer: "Website made by Raj Sharma".

IMPORTANT
1. Open app.js.
2. Find:
   const OWNER_WHATSAPP = "91XXXXXXXXXX";
3. Replace it with the owner's WhatsApp number including country code and digits only.
   Example: 919876543210
4. Open index.html in a browser, or upload the folder to your hosting.

The WhatsApp button intentionally does not process payments. The store manually confirms stock, final price and delivery.
